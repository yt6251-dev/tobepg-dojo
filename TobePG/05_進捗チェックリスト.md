## 卒業条件（12/13 Gate 3）

12項目中 **10項目**で卒業。8〜9なら2週延長。7以下なら計画を見直す。

### 実装力
- [ ] ドリル 累計65問以上（Exercism 20 / LeetCode easy 30 / medium 15）
- [ ] LeetCode medium を60分以内に通せる確率が半分以上（直近10問で5問）
- [ ] 2時間の実装試験3回のうち2回 制限時間内にテストまで通った
- [ ] TestLens で自分の手で書いた行数が1,500行以上（`git log --author --numstat` で集計）

### 設計力
- [ ] TestLens の構成を15分で口頭説明した録画があり 自分で直した点が3つある
- [ ] ER図 / API契約 / 権限表 を自分で書いた（AIの雛形を使わず）
- [ ] 元町Cal の権限表が138行埋まっている

### 運用と品質
- [ ] TestLens が公開URLで動き CI が緑で Sentry が入っている
- [ ] Vitest 50件以上 Playwright 5本以上
- [ ] 元町Cal に認証ミドルウェアが入り 30エンドポイント以上が「拒否」に切り替わっている

### 実績と発信
- [ ] OSS の PR が1本マージされた（またはレビュー1往復以上）
- [ ] Zenn の記事が10本以上公開されている

